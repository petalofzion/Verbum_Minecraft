# Agent Logs (Librarian's Desk Capsule)

Use this folder to record questions, issues, and decisions for this capsule.

## Naming

Allowed `type`: `issue`, `question`, `decision`, `risk`, `todo`

## Template
See `LOG_TEMPLATE.md`.

## Archive
Move resolved historical logs to `archive/` when needed.
