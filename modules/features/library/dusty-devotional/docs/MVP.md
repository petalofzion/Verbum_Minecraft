# MVP: Dusty Devotional

## Must-Have
- Dusty Devotional item registered via `FeatureEntrypoint` using `LibraryBookDef`.
- Book id includes Veritas edition marker.
- Concise profile manual text in Veritas tone.
- Item assets, lang entry, SPI registration, and module metadata in place.

## Out of Scope (for MVP)
- Additional profile manuals.
- Dynamic localization workflow.
- Custom interactions beyond default library-backed reading.

## Acceptance Criteria
- Item id is stable as `verbum:dusty_devotional`.
- Book opens from packaged text resource.
- Manual text is plain, grounded, and non-preachy.
- No Minecraft/Fabric classes used in the capsule.
