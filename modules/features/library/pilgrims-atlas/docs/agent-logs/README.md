# Agent Logs (Pilgrim's Atlas Capsule)

Use this folder to record questions, issues, and decisions for this capsule.

## Naming
`YYYY-MM-DD_<type>_<slug>.md`

Allowed `type`: `issue`, `question`, `decision`, `risk`, `todo`

## Template
See `LOG_TEMPLATE.md`.

## Archive
Move resolved or superseded logs under `archive/`.

## Relation to TODO
If a log results in new capsule work, add it to `docs/TODO.md`.
