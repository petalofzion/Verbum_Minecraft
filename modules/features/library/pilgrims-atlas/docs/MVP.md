# MVP: Pilgrim's Atlas

## Must-Have
- Pilgrim's Atlas item registered via `FeatureEntrypoint` using `LibraryBookDef`.
- Book id includes Visions edition marker.
- Concise profile manual text in Visions tone.
- Item assets, lang entry, SPI registration, and module metadata in place.

## Out of Scope (for MVP)
- Additional profile manuals.
- Dynamic localization workflow.
- Custom interactions beyond default library-backed reading.

## Acceptance Criteria
- Item id is stable as `verbum:pilgrims_atlas`.
- Book opens from packaged text resource.
- Manual text is helpful first, mythic second, and clearly frames Visions as flagship.
- No Minecraft/Fabric classes used in the capsule.
