# Agent Logs (Rule of Ashes Capsule)

Use this folder to record questions, issues, and decisions for this capsule.

## Naming
`YYYY-MM-DD_<type>_<slug>.md`

Allowed `type`: `issue`, `question`, `decision`, `risk`, `todo`

## Template
See `LOG_TEMPLATE.md`.

## Archive
Move resolved/superseded entries into `archive/`.
