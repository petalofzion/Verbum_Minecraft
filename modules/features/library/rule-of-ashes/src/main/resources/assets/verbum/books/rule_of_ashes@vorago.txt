Rule of Ashes

This manual names the Vorago line.
It is not a second world.
It is Visions under stricter law.
---PAGE---
In Vorago, pressure is constant.
Time costs more.
Mistakes last longer.
Comfort is temporary.
---PAGE---
Scarcity is instructional.
Count food, fuel, and shelter before ambition.
Spend tools with intent.
Carry only what you can afford to lose.
---PAGE---
Risk is part of normal play.
Scout first.
Commit late.
Leave a clear return route.
Treat night, weather, and distance as threats.
---PAGE---
Discipline keeps you alive.
Build routines.
Stock reserves.
Repair before failure.
Advance only when your margin is real.
---PAGE---
Vorago does not reward panic.
It rewards attention, restraint, and repetition.
If you endure, the same world opens again,
but only to a prepared hand.
